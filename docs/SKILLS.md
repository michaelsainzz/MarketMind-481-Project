# Project workflow catalog

Canonical procedures live in `.agents/skills/`. Each folder contains SKILL.md
with name/description frontmatter. Read only the relevant procedure for a task.

| Skill | Use |
| --- | --- |
| implement-task | Turn a scoped task into a verified implementation and evidence record |
| review-change | Review a diff against acceptance criteria and report actionable findings |
| marketmind-product-manager | Develop product ideas, prioritize epics/stories, and maintain evidence-based scope and delivery plans |

For product work, use `marketmind-product-manager` and start with
`docs/product/BRIEF.md` and `docs/product/BACKLOG.md`. Example:

> Use $marketmind-product-manager to develop this idea, recommend its smallest
> useful version, and update the backlog with acceptance criteria and tradeoffs.

If native skill discovery is unavailable, ask the agent to read
`.agents/skills/marketmind-product-manager/SKILL.md` explicitly. The role runs
within the invoked agent session; it is not a deployed or unattended agent.

Claude copies are generated by `python scripts/sync_skills.py`.
Gemini CLI supports the canonical .agents/skills workspace alias.
If native discovery is unavailable, explicitly ask the tool to read the file.
Do not claim that an untested tool installation successfully discovered a skill.
